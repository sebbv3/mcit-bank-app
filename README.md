# MCIT Bank Application

**Student:** Sebastian Vita

## Project Overview

This project is a Flask banking application created for the MCIT Python Programming course.

The application allows the user to:

- View account information
- View the current balance
- Make deposits
- Make withdrawals
- View total deposits and withdrawals
- View transaction history
- Receive success and error messages
- Use a responsive interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Jinja

## Features

- Starting balance of $1,000 CAD
- Deposit functionality
- Withdrawal functionality
- Insufficient funds validation
- Transaction history
- Total deposits and withdrawals
- Responsive design
